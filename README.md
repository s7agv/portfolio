# Portfólio Profissional - Gustavo Ramos Starling

Website de portfólio profissional para o LAB01 da disciplina DIW (PUC Minas).

## Descrição do projeto

Site com 4 seções (Sobre Mim, Projetos, Experiências, Contato) em português e
inglês, apresentando formação, trajetória e projetos pessoais.

## Tecnologias previstas

- HTML / CSS / JavaScript
- [Material Web Components](https://github.com/material-components/material-web) para UI
- [Three.js](https://threejs.org/) para elementos 3D
- [EmailJS](https://www.emailjs.com/) para envio do formulário de contato sem backend
- Deploy: [Vercel](https://vercel.com/)

## Estrutura do projeto

```
├── index.html          # Sobre Mim
├── projects.html        # Projetos (timeline)
├── experience.html      # Experiências
├── contact.html          # Contato
├── css/style.css
├── js/
│   ├── nav.js            # navegação + toggle PT/EN
│   ├── projects-data.js  # dados dos projetos
│   └── hero3d.js         # animação three.js
└── assets/img/
```
